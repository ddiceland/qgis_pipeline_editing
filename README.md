# 管网编辑工具

QGIS 插件，面向管网数据的加载、编辑、裁剪导出与入库。最低版本 **QGIS 3.18**（不支持 4.x）。

插件菜单与工具栏入口均为「管网编辑工具」，打开右侧停靠面板。配置保存在本插件目录 `config/profiles.json`；PostgreSQL 账号密码保存在 QGIS 的 `QSettings`（组名 `PipelineEditingPlugin/pg_connection`），不写入 JSON。

本插件与「管网导出」「MDB 渲染」等其它插件相互独立，互不改对方代码与配置。

---

## 1. 能做什么

| 页签 | 能力 |
|------|------|
| **总数据库** | 从 PostgreSQL/PostGIS 加载总管点、总管线；按多边形裁剪后导出为 MDB 或 GDB/GPKG |
| **MDB数据库** | 打开 Access（`.mdb` / `.accdb`），按结构组加载为可编辑内存图层，保存改回、入库到总库、结构转换 |
| **TXT管线** | 打开测绘 TXT 坐标文件，表格编辑后保存，并加载为线图层 |

底部有运行日志。面板顶部「配置管理」打开全部业务配置。

---

## 2. 环境与依赖

| 依赖 | 用途 |
|------|------|
| QGIS 3.18+ | 宿主（开发与测试基于 3.44 LTR，不支持 4.x） |
| `psycopg2` / `psycopg2-binary` | 连接 PostgreSQL、入库与导出取数 |
| `pyodbc` + **Microsoft Access Database Engine** | 读写 MDB |
| GDAL **FileGDB** 驱动（可选） | 写出 `.gdb`；没有时可退回 GeoPackage（`.gpkg`） |

在 QGIS 自带 Python 中安装：

```text
python3 -m pip install psycopg2-binary pyodbc
```

首次使用：

1. 将本目录放到 QGIS 插件路径（或用「从 ZIP 安装」）。
2. 插件管理器中启用「管网编辑工具」。
3. 打开「配置管理」：填 PostgreSQL 连接 →「测试连接」→「加载表结构」→ 底部「保存」。
4. 按实际 MDB 填写「MDB库渲染」「MDB库结构」「结构映射」。

改代码后，若 QGIS 加载的是另一份插件副本（例如 AppData 下的安装目录），需要把改过的 `.py` 同步过去再重新加载插件。不要用开发目录的 `profiles.json` 覆盖正在用的那份配置。

## 3. 管类与 FZ

内置管类代码见 `core/pipe_catalog.py`（给水 JS、雨水 YS、污水 WS、综合管沟 ZH、辅助 FZ 等）。界面显示为 `代码 (中文名)`。

**FZ 不是独立管类**，表示辅助数据：

- 总库用 `ptype` 表示真实管类，`gtype` 非空表示辅助。着色按 `ptype`，与主数据同色。
- 勾选 FZ 时必须同时勾选至少一种其它管类。
- 非全选时，FZ 只保留「管线类型」属于已勾选基础管类的行。
- 「MDB库渲染 → 管线类型」为空时，无法按勾选管类筛 FZ，加载/入库会跳过 FZ（全选可用管类时仍加载全部 FZ）。
- 入库时 FZ 的 `ptype` 取行内管类字段（如 YS、WS），`gtype` 写 `FZ`。井编号按该行真实管类续编，**不用 FZ 前缀**。
- 源表缺少已配置的管类字段，或 FZ 某行管类为空：**整次入库中止并回滚**。

西安结构默认把 **ZH、FZ** 标为独立管类（`independent_pipes`），字段映射可按管类单独配；正元结构默认没有独立管类。

## 4. 配置管理

路径：面板「配置管理」。窗口标题栏可最小化 / 最大化。改完必须点对话框底部 **保存**，才会写入 `config/profiles.json`。

「数据库连接」里的「保存配置」只写 PostgreSQL 账号（QSettings）和当前表名到内存，仍须再点底部「保存」才能持久化表结构快照。

### 4.1 数据库连接

- 主机、端口、库名、用户、密码。
- 管点表 / 管线表的 schema、表名。
- 管线最大井编号视图表（默认字段 `ptype`、`max_expno`），用于总库管类列表和入库续编井号。
- 关键字段：点 geom、点主键、**点井编号**（默认 `expno`，管点与管线按井号关联）、点管线种类、点 gtype；线 geom、线起点号、线终点号、线管线种类、线 gtype。
- 「加载表结构」：从库中拉取列清单和视图表中的管类，覆盖写入配置中的表结构快照。

点表 `id` 只是库内主键；**点 ↔ 线业务关联是井编号**（点井编号 ↔ 线起点号 / 线终点号）。裁剪导出补框外端点时也按井编号查询，这三项缺一不可。

视图表里没有的管类，在「总数据库」页会灰掉禁用。

### 4.2 管类颜色

加载总库图层、MDB 合并图层时，按此处颜色分类着色。

### 4.3 规则集

给「结构映射」做字段值转换，内置：

| 规则 | 作用 |
|------|------|
| 材质 / 埋设方式 | 中文名称 ↔ 代码对照 |
| 角度换算 | 角度 ↔ 弧度 |
| 时间 | `2026-08-22` ↔ `20260822`；写出类型按目标库结构（日期或文本） |
| 顺序号 | 按行生成序号 |
| 井编号 | 入库时续编（重编井号）或对照更新 |
| XYZ | 从坐标字段或几何取 X/Y/Z |

可新增自定义对照类规则。对照表说明列仅供查看，不参与转换。

### 4.4 MDB库渲染

**打开/加载 MDB 时识别表、建几何、分类着色**。新增结构组时按名称生成内部编号：汉字转拼音（如「秦华结构」→ `qinhua`），英文名直接用小写。正元 / 西安仍为 `zhengyuan` / `xian`。

**先配渲染组，再配库结构**：后面的「MDB库结构」和结构映射都沿用这个编号。只配了渲染组也可以加载查看；未配渲染组就去做结构转换会提示先来这里配置。

每组填写：

- 点/线表命名，`{code}` 表示管类，如 `{code}POINT`、`{code}_POINT`
- 点：井编号、X、Y；线：起点、终点（或连接方向）
- **管线类型（可选）**：留空则按表名认管类；填写则用于合并图层着色，**不写回 MDB**

内置两组：正元（如 `JS_POINT` / 物探点号）、西安（如 `JSPOINT` / EXPNO）。打开 MDB 时按表名+字段匹配其中一组，**字段名区分大小写**（用来分开西安 `EXPNO` 和老西安 `ExpNo`），匹配不到会报错。

### 4.5 MDB库结构

入库、导出、结构转换的**目标/源表结构**：每管类点表名、线表名、字段类型与长度。

- **新增结构**时选择一个还没有库结构的「MDB库渲染」组，编号和名称与该组相同，不能再单独起一套 id。
- 新增后默认带上目录中的全部管类。「管线种类」可再 **新增** / **删除选中**。
- 可设模板管类（须是当前列表中的一种，默认 JS）和独立管类（逗号分隔，如 `ZH,FZ`）。独立管类须属于本结构已列出的管类。

字段表四列：

| 列 | 用途 |
|----|------|
| 字段名 | Access 字段名 |
| MDB类型 | TEXT、SINGLE、DOUBLE 等 |
| MDB大小 | **仅文本**：字符长度（如 50） |
| 小数位数 | **仅单精度 / 双精度**：写出时四舍五入的小数位，默认 3（0～8） |

建表 DDL 仍按 Access 类型（`TEXT(n)` / `DOUBLE`），小数位**不写入列定义**，只在写出数值时生效（导出、结构转换、入库、MDB 保存）。空着的浮点字段按 3 位处理。整数、日期等类型两列均不可改。

### 4.6 结构映射

三个子页：

| 页 | 用途 |
|----|------|
| **导出映射** | 总库字段 → MDB/GDB 字段（总数据库「导出」） |
| **导入映射** | MDB 字段 → 总库字段（「数据入库」） |
| **结构转换** | 源结构字段 → 目标结构字段（「结构转换」）；可生成反向映射 |

映射行可挂规则集（材质代码、时间、井编号、XYZ 等）。未配置有效字段行时，对应导出/入库/转换会拒绝执行。结构转换的源结构按打开的 MDB 匹配渲染组得到内部编号，须与这里选择的源结构编号一致。缺渲染组、缺库结构、缺映射会分别提示。

## 5. 总数据库

### 5.1 加载

1. 勾选管类（视图表没有的为灰）。
2. 点「加载」。

结果图层（图层组 **「总库」**）：

- **总管线**：可见，按 `ptype` 着色；百万级表会开 `estimatedmetadata`、几何简化。
- **总管点**：默认关闭显示。

全选视图表中全部可用管类时，不再加 SQL 子集过滤（整表打开）。部分勾选时：

- 普通管类：`ptype IN (...) AND gtype IS NULL`
- 同时勾 FZ：再加上对应 `ptype` 且 `gtype IS NOT NULL` 的辅助数据

### 5.2 裁剪与导出

1. 「绘制裁剪范围」：左键加点，右键或双击结束，Backspace 撤销。
2. 勾选管类、选择导出结构（对应「MDB库结构」）和格式（MDB 库 / GDB 库）。
3. 「导出」。范围内没有已勾选管类数据则不写文件。
4. 导出会弹出进度窗：当前管类、百分比、预计剩余 / 已用时间。点 **停止导出** 可中断：先显示「正在停止…」，当前管类处理完后进度窗**自动关闭**，再弹出停止结果。已完成的管类留在结果文件中，正在写的那一类不计入；停止后**不清除**裁剪范围。
5. **全部导出成功后会清除裁剪多边形**，需再导出请重新绘制。成功弹窗列出各管类点数/线数，并给出合计。

跨边界管线会按 **点井编号** 补上框外起终点（不是点表 `id`）。点井编号、线起点号、线终点号未配置时，有相交管线会报错。

GDB：要素类带 OBJECTID 与 Shape，**不写坐标系**。本机没有可写 FileGDB 驱动时，可改为 GeoPackage（几何列名仍用 Shape）。画布 CRS 仅用于把裁剪多边形转到库的 SRID 做空间查询。

导出按「导出映射」写字段，并套规则集；浮点字段再按**目标**「MDB库结构」的小数位数收口。FZ 辅助行按勾选的基础管类过滤。

## 6. MDB 数据库

### 6.1 打开与加载

1. 「打开MDB库」→ 列出库内有数据的管类（空表灰掉）。仅点表有数据的管类仍可加载，只出点图层。
2. 「加载」：测绘坐标（**交换 X/Y** 后上图，默认）。
3. 「加载(不交换XY)」：数学坐标（X 东 Y 北，与地图一致）。

加载结果为两个**合并内存图层**（无 CRS），放在图层组 **「MDB库」**：

- **MDB管点**
- **MDB管线**

多管类合在一层，内部字段 `_mdb_pipe` 记录来源表管类，**符号按 `_mdb_pipe` 着色**（不受「管线类型」列显示值影响）。保存时 `_mdb_pipe` 和可选的管线类型显示列不写回 MDB。

若源表已有管线类型列，属性里显示库中原值；没有该列时才按表名盖章。路由始终按 `_mdb_pipe`。

### 6.2 保存修改

「保存修改」把图层上的属性/几何写回已打开的 MDB。

- **不支持向已有 MDB 新增要素**（新画的要素会报错，需先删再保存）。
- 可更新、删除已有行。
- 点移动后按点号同步线端点；改点表 X/Y 会重建点几何。
- 写回浮点数值：
  - 打开的库能匹配到同 id 的「MDB库结构」：结构里的单精度/双精度按该字段小数位取整（空则 3）；结构未列出的字段不改，但 X/Y 仍 3 位。
  - 仅匹配到「MDB库渲染」、没有对应结构：只有 X/Y 保留 3 位，其余按修改原样保存。
- 交换 XY 的会话按加载时的方式反变换。
- 保存后更新内存快照并重绘，**不会从 MDB 整表重读**。

### 6.3 数据入库

把当前打开的 MDB 按「导入映射」写入 PostgreSQL 总库（**同一事务**，失败或停止都回滚）。

- 须先加载图层，以便确认结构和 XY 交换方式。
- 未勾选管类、空表不入库。
- 入库弹出进度窗（当前管类、百分比、预计剩余 / 已用时间）。点 **停止导入** 会中断并回滚：先显示「正在停止…」，回滚完成后进度窗**自动关闭**，**PostgreSQL 中一条数据都不会留下**。
- 井编号：导入映射里选了「井编号」规则的字段会按视图表续编或对照更新；未选则用原井号。
- 浮点字段按**源**「MDB库结构」的小数位数收口后再写入 PostgreSQL。
- FZ 规则见第 3 节。

### 6.4 结构转换

按「结构映射 → 结构转换」把源 MDB **另存**为目标结构的新 MDB 或 GDB，**不覆盖源文件**。成功弹窗列出各表行数，并合计管点、管线数量。浮点字段按**目标**结构的小数位数收口。

源、目标结构相同时，仍可导出为带 OBJECTID/Shape 的矢量库，字段结构不变。

### 6.5 其它

- 「移除图层」：从工程去掉本次加载的 MDB 图层。
- 「关闭」：关掉当前 MDB 路径（需先处理已加载图层）。

## 7. TXT 管线

### 文件格式

- 编码：UTF-8（可带 BOM）、GBK、GB2312。
- 第一行前两个字符为管类代码。
- 其后每行：`x1,y1,z1;x2,y2,z2;管径`

### 操作

打开后可在表格中改坐标与管径（同点号接头会联动）、新增/删除行，再「保存」写回文件。

「加载」/「加载(不交换XY)」生成无 CRS 的线图层（图层组 **「TXT坐标」**），规则与 MDB 相同：默认交换测绘 XY。「关闭」会卸掉该文件对应图层；组空则一并去掉。

## 8. 坐标与坐标系

测绘数据里常见 **X 北、Y 东**，与 QGIS 地图（X 东、Y 北）相反。

| 按钮 | 数据 → 地图 |
|------|-------------|
| 加载 | `(地图X, 地图Y) = (数据Y, 数据X)` |
| 加载(不交换XY) | 原样 |

保存 MDB / 导出写回文件时做反向变换。

以下图层**不设置 CRS**（空坐标系）：MDB 内存层、TXT 层、GDB Shape。总库图层使用 PostGIS 表自身的 SRID。

## 9. 配置文件说明

`config/profiles.json` 当前顶层字段：

| 键 | 内容 |
|----|------|
| `pg_config` | 点/线表、井编号视图表及关键字段名（含 `wellno_field` 点井编号） |
| `pg_table_schemas` | 「加载表结构」得到的列快照与管类列表 |
| `pipe_colors` | 管类颜色 |
| `mdb_render_groups` | MDB 渲染结构组 |
| `mdb_structures` | MDB 库结构（含字段 `mdb_type` / `mdb_size` / `decimal_places`） |
| `structure_mappings` | 导出 / 导入 / 结构转换映射 |
| `rule_sets` | 规则集 |

旧版顶层 `zhengyuan`、`xian`、`material_config`、`dtype_config`、`custom_structures` **加载时仍会识别并迁移**，保存时不再写回。打开配置管理时若检测到迁移，会自动保存一次新格式。

账号不在 JSON 里。首次若本插件还没有连接信息，会尝试从旧导出插件的 QSettings（`PipeExportPlugin/pg_connection`）复制一次。

## 11. 注意事项

- 总库点层默认隐藏，并非加载失败。图层组：「总库」「MDB库」「TXT坐标」。
- 已有 MDB **不能靠本插件加新点、新线**；要新增请在库外处理或换新库再导入。
- 保存不会改管类归属：要素仍写回 `_mdb_pipe` 对应的原表。
- 入库缺管类字段会整批失败，避免半写入。
- 使用 MDB 时先配「MDB库渲染」（产生内部编号），需要转换/入库/导出时再配同编号的「MDB库结构」和结构映射。未配渲染组不要做结构转换。
- 绘制裁剪范围后务必导出前确认已选结构和格式；**全部成功**后范围会清空。中途停止导出则保留范围；停止导出 / 停止导入后进度窗会自动关掉，不必手动关。
- 浮点精度以「MDB库结构 → 小数位数」为准；二进制浮点无法保证磁盘比特等于十进制，读出后再按同样位数显示应一致。
- 不要把 `profiles.json` 提交到公开仓库（可能含库内表结构）；密码在 QSettings，备份配置时一并考虑。
